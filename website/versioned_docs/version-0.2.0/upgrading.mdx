# Upgrading the Plugin

When you upgrade to a plugin version with breaking changes or deprecated DSL elements, you may need
to change your build. This page lists those changes by version.

For the full list of changes in each version, including new features and fixes, see the
[plugin releases on GitHub](https://github.com/onec-devops/onec-gradle-plugin/releases).

## Upgrade Steps {/* #steps */}

1. Read the sections below for every version between your current version and the new one.
2. Update the plugin version in the `plugins` block.
3. Apply the changes described in those sections, then build the project.

Version 0.2.0 has no breaking changes or deprecated DSL elements.
