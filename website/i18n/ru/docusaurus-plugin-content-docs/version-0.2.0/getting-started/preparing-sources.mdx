# Подготовка исходного кода

Исходный код для сборки - это XML-выгрузка из конфигуратора или проект 1С:EDT. Если исходный код уже
готов, сразу переходите на страницу [Сборка проекта](./first-build.mdx).

## Содержимое каталога исходного кода {/* #sources-directory */}

Плагин определяет тип проекта по содержимому каталога исходного кода, который задаёт свойство
`srcDir`. Поэтому выгрузка должна оказаться прямо в нём, без
вложенного каталога.

<Tabs groupId="source-format">
<TabItem value="xml" label="XML">

Конфигурация или расширение:

```text
src/
├─ Configuration.xml
├─ Catalogs/
├─ Documents/
└─ ...
```

Внешняя обработка:

```text
src/
├─ DataProcessor.xml
└─ DataProcessor/
```

Внешний отчёт:

```text
src/
├─ Report.xml
└─ Report/
```

Для совместимости с готовыми выгрузками имена файлов могут быть любыми, например `Invoice.xml` и
`Invoice/`. Но рекомендуется называть их `DataProcessor` и `Report`, как в примерах: тогда имена
файлов не зависят от имени объекта и не меняются при его переименовании.

</TabItem>
<TabItem value="edt" label="1С:EDT">

Каталог исходного кода - это сам каталог проекта 1С:EDT любого типа, с файлом `.project` и
каталогом `DT-INF/`:

```text
src/
├─ .project
├─ DT-INF/
│  └─ PROJECT.PMF
└─ src/
```

Проект внешних обработок и отчётов собирается в один артефакт, поэтому в нём должна быть ровно одна
обработка или отчёт.

</TabItem>
</Tabs>

## Выгрузка и размещение исходного кода {/* #exporting-sources */}

<Tabs groupId="source-format">
<TabItem value="xml" label="XML">

Исходный код выгружается из конфигуратора, для каждого типа проекта своей командой.

Чтобы выгрузить конфигурацию:

1. Выберите **Конфигурация** > **Выгрузить конфигурацию в файлы**.
2. Укажите каталог исходного кода.

Чтобы выгрузить расширение:

1. Откройте расширение через **Конфигурация** > **Расширения конфигурации**.
2. Выберите **Конфигурация** > **Выгрузить конфигурацию в файлы**.
3. Укажите каталог исходного кода.

Чтобы выгрузить внешнюю обработку или отчёт:

1. Откройте файл через **Файл** > **Открыть**.
2. Выберите **Действия** > **Выгрузить в файлы**.
3. Сохраните `DataProcessor.xml` или `Report.xml` в каталоге исходного кода.

Для выгрузки из командной строки есть утилита `ibcmd`, см.
[руководство администратора](https://its.1c.ru/db/v8314doc#bookmark:adm:TI000000894).

</TabItem>
<TabItem value="edt" label="1С:EDT">

Проект 1С:EDT можно сразу создать в каталоге исходного кода или перенести туда существующий.

Чтобы создать новый проект:

1. Создайте проект в 1С:EDT.
2. Укажите каталог исходного кода как расположение проекта.

Чтобы перенести существующий проект:

- Скопируйте каталог проекта в каталог исходного кода.

:::tip

Чтобы продолжить работу с проектом, импортируйте его из каталога исходного кода в рабочую область
через **Файл** > **Импорт** > **Проект в рабочую область**.

:::

Для сборки укажите версию 1С:EDT в `edtVersion`, см.
[Добавление плагина в скрипт сборки](./first-build.mdx#applying-the-plugin).

</TabItem>
</Tabs>
