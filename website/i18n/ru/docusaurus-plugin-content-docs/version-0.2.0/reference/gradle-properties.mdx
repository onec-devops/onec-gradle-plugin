# Свойства Gradle

Плагин поддерживает следующие свойства Gradle.

## `onec.edt.installations.fromEnv` {/* #onec-edt-installations-fromenv */}

**По умолчанию:** `EDT_HOME`

Переменные окружения, в каждой из которых один путь к установке 1С:EDT.

```properties
onec.edt.installations.fromEnv=EDT_HOME,EDT_2026
```

## `onec.edt.installations.paths` {/* #onec-edt-installations-paths */}

**По умолчанию:** нет

Каталоги установленной 1С:EDT или каталоги, где установлено несколько её версий.

```properties
onec.edt.installations.paths=D:/1C/EDT
```

## `onec.installations.fromEnv` {/* #onec-installations-fromenv */}

**По умолчанию:** `ONEC_HOME`

Переменные окружения, в каждой из которых один путь к установке платформы.

```properties
onec.installations.fromEnv=ONEC_HOME,V8_HOME
```

## `onec.installations.paths` {/* #onec-installations-paths */}

**По умолчанию:** нет

Каталоги установленной платформы или каталоги, где установлено несколько её версий.

```properties
onec.installations.paths=D:/1cv8,E:/1C/8.3.25.1633
```
