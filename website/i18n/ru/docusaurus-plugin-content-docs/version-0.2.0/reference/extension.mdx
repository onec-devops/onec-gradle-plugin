# Блок `onec`

Блок `onec` - расширение (extension) Gradle, через которое настраивается плагин.

## `edtVersion` {/* #edtversion */}

**Тип:** `Property<String>`\
**По умолчанию:** нет

Версия 1С:EDT, которой собирается проект: полная, например `2026.2.2`, или её начало,
например `2026.2`. Из подходящих установок плагин берёт самую новую. Обязательно только для
сборки проекта 1С:EDT, для XML-выгрузки не нужно.

Плагин ищет 1С:EDT в таком порядке, а из нескольких установок одной версии берёт найденную
первой:

1. Пути из свойства Gradle `onec.edt.installations.paths`.
2. Пути из переменных окружения, названных в
   `onec.edt.installations.fromEnv`, по умолчанию `EDT_HOME`.
3. Стандартные каталоги: в Windows `%LOCALAPPDATA%\1C\1cedtstart\installations` (1С:EDT Start)
   и `%ProgramFiles%\1C\1CE\components` (установщик 1С:Предприятия), в Linux
   `/opt/1C/1CE/components`.

## `platformVersion` {/* #platformversion */}

**Тип:** `Property<String>`\
**По умолчанию:** нет

Версия платформы, на которой собирается проект: полная, например `8.3.25.1633`, или её начало,
например `8.3.25`. Из подходящих установок плагин берёт самую новую. Обязательно для сборки.

Плагин ищет платформу в таком порядке, а из нескольких установок одной версии берёт найденную
первой:

1. Пути из свойства Gradle
   `onec.installations.paths`.
2. Пути из переменных окружения, названных в
   `onec.installations.fromEnv`, по умолчанию `ONEC_HOME`.
3. Стандартные каталоги: в Windows `%ProgramFiles%\1cv8` и `%ProgramFiles(x86)%\1cv8`, в Linux
   `/opt/1cv8/<архитектура>`.

Каталог установки платформы называется по её версии; ссылка на него, например
`/opt/1cv8/current`, тоже подходит. Какие установки нашёл плагин, показывает задача
`onecInstallations`.

## `srcDir` {/* #srcdir */}

**Тип:** `DirectoryProperty`\
**По умолчанию:** `src`

Каталог исходного кода: XML-выгрузка или проект 1С:EDT конфигурации, расширения, внешней обработки
или внешнего отчёта. Формат и тип исходного кода плагин определяет по файлам.

Как подготовить исходный код, описано на странице [Подготовка исходного кода](../getting-started/preparing-sources.mdx).
