# Обновление плагина

На этой странице описано, что поменять в сборке при переходе на версию плагина с
несовместимыми изменениями или устаревшими элементами DSL.

Полный список изменений каждой версии, включая новые возможности и исправления, есть в
[релизах плагина на GitHub](https://github.com/onec-devops/onec-gradle-plugin/releases).

## Порядок обновления {/* #steps */}

1. Прочитайте разделы ниже для всех версий между текущей и новой.
2. Поменяйте версию плагина в блоке `plugins`.
3. Внесите в сборку изменения из этих разделов и соберите проект.

## Обновление до 0.3.0 {/* #upgrade-to-0-3-0 */}

### Свойства поиска платформы переименованы {/* #platform-properties-renamed */}

Свойства Gradle, по которым плагин находит платформу, переименованы, а старые имена больше не
читаются. Сборка, где заданы старые свойства, не находит платформу вне стандартных каталогов.

| Старое имя | Новое имя |
|---|---|
| `onec.installations.paths` | `onec.platform.installations.paths` |
| `onec.installations.fromEnv` | `onec.platform.installations.fromEnv` |

Чтобы сборка снова находила платформу, переименуйте свойства там, где они заданы, например в
`~/.gradle/gradle.properties`.

### Минимальная версия Gradle - 9.1 {/* #minimum-gradle-9-1 */}

Плагин работает на Gradle 9.1.0 или новее. На Gradle 9.0.x сборка завершается ошибкой
`The onec plugin requires Gradle 9.1.0 or newer`.

Чтобы сборка снова работала, переведите проект на новый Gradle через Gradle Wrapper:

```bash
./gradlew wrapper --gradle-version <версия>
```
